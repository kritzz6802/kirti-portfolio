# Wedding invitation — `/invitation/`

A standalone animated wedding invitation, written in plain HTML, CSS and JavaScript (no framework).
It lives beside the portfolio, but nothing in the portfolio depends on it.

```
public/invitation/
├── index.html      markup for the envelope, the hero card and nine sections, plus an inline SVG sprite
├── styles.css      layout, the envelope in 3D, reveals, keyframes, responsive and reduced-motion rules
├── script.js       invitationData (all content), timeline, auto-tour, countdown, music, replay
├── assets/
│   ├── illustrations/   painted SVGs (generated — see below)
│   ├── audio/           wedding-loop.mp3 (original; replace with your own if you like)
│   ├── fonts/           optional self-hosted fonts (Google Fonts is used by default)
│   └── images/          optional photos
└── README.md
```

## Run it

| How | URL |
| --- | --- |
| `npm run dev` | <http://localhost:5173/invitation/> |
| `npm run build && npm run preview` | <http://localhost:4173/invitation/> |
| Netlify / Apache (`dist/`) | `https://<site>/invitation/` |
| No server | open `public/invitation/index.html` directly (works from `file://`) |

In dev and preview, a small plugin in `vite.config.ts` (`invitationRoute`) answers `/invitation/` with this
page. Without it, Vite's SPA fallback would serve the portfolio there. In production the file is
served as-is from `dist/invitation/`.

## Change the content

Every visible value comes from the `invitationData` object at the top of `script.js`. Nothing else
needs editing.

- **Names, wording, venue:** `personOneName`, `personTwoName`, `openingMessage`, `venue`, `city`, `address`,
  `hostNames`, `contact`, `additionalMessage`.
- **Dates:** `date` and `rsvpBy` take `YYYY-MM-DD`; `time` takes 24-hour `HH:MM`. The weekday, month name, the
  date strip on *The Day* and the countdown are all derived from these values. `utcOffset` is the venue's offset
  (`+05:30` for India), which the countdown uses.
- **Lists:** `story` (paragraphs), `program` (each has `time`, `title` and an `icon` from `cheers`, `rings`,
  `bouquet`, `dinner`, `cake`, `dance` or `moon`), and `hotels`.
- **Links:** `mapUrl` (if left empty, the page searches the venue on Google Maps), `rsvpUrl`, `gift.url`, `hotels[].url`.
  A button whose link is empty is hidden, so no button leads nowhere.
- **Auto tour:** `autoTour: false` keeps the page still after the reveal, so the guest scrolls by hand.

## Music

`assets/audio/wedding-loop.mp3` plays from the tap that opens the envelope. It is an original 63-second loop
rendered by `scripts/invitation-music.py` (tanpura, santoor-like plucks, a bansuri-like melody and a soft dholak),
so there are no licensing worries.

To use your own track, put the file in `assets/audio/` and point `music.src` at it; `music.volume` takes a value
from 0 to 1. The sound button (bottom-left) appears once the track has loaded. It fades the music out and back in,
and the music pauses while the tab is hidden.

## Fonts and images

The fonts are Cormorant Garamond (serif) and La Belle Aurore (the handwritten signature), both from Google Fonts.
To self-host them, put the files in `assets/fonts/`, add `@font-face` rules at the top of `styles.css`, and remove
the `<link>` to fonts.googleapis.com in `index.html`.

To use a photo, put it in `assets/images/` and point an `<img>` at it. Use `object-fit: cover` so it keeps its
proportions.

## Illustrations

The painted look comes from SVG filters: displacement for the ragged brush edges, plus a lighting pass for the
impasto texture. The SVGs are generated by `scripts/invitation-illustrations.py`, and the output is seeded, so the
same input always gives the same files:

```bash
python3 scripts/invitation-illustrations.py public/invitation/assets/illustrations
```

Edit the colours, counts or shapes in that script and run it again. Any SVG can also be replaced with your own
artwork under the same file name.

## The reference and the scene plan

The design follows the Instagram reel `instagram.com/reel/Dew6je2R9Fb` (28.6 s, 720×1280, 30 fps). The reel is a
phone scrolling through a Mediterranean watercolour wedding website. The reel's own artwork was not copied: every
scene here is redrawn as SVG, as close to the reel as was feasible.

| # | Reel | Here | Timing (from the tap) |
| --- | --- | --- | --- |
| 1 | Closed envelope: a painted coastal village, a white blossom branch top-left, a frayed silk ribbon and bow | Same layers. The ring on the bow pulses, with a "Tap the ribbon to open" hint | before the tap |
| 2 | The ribbon comes off | The bow slips and shrinks; the two halves of the ribbon slide apart along its diagonal | 0 – 1.5 s |
| 3 | The flaps fold open onto lilac paper | Top flap, then left/right, then bottom, each turning in 3D on its own hinge, with a shadow underneath | 1.25 – 3.7 s |
| 4 | The painted sky frame blooms around the lilac card | The envelope lifts away; the sky reveals inward from the edges while settling from 114 % to 100 %; the castle rises in | 3.5 – 6 s |
| 5 | Names, "We invite you…", date, venue | The names appear letter by letter, out of a blur; the invitation line word by word; two butterflies flutter in; month → day → weekday → year; the venue is revealed left to right | 4.2 – 8 s |
| 6 | Scroll: Countdown in a blue-and-white tile frame with pink blossoms | The countdown counts up to the live value, then ticks every second | auto tour from 10.2 s |
| 7 | Our Story under painted clouds, signed by hand; a fountain garden fades into dark green | Same | |
| 8 | The Celebration: a cream line-art frame on dark green, View on Map; a hillside villa leads back to lilac | The frame draws itself in (stroke animation) | |
| 9 | The Day: a date strip with a heart, and a timeline with small illustrations | The heart beats; the timeline line grows; the items appear one after another | |
| 10 | Dress Code: guests in pastel gowns and black suits under a green garland | Same | |
| 11 | Welcome Soirée: dark green with pink petals spilling in | Petal edges at both ends, plus a few falling petals | |
| 12 | Where to Stay, Wedding Gift (a floral wreath), RSVP (a window with flowers and a butterfly) | Same; the wreath turns slowly; the tour ends on RSVP and holds there | ends ≈ 45 s |

**Deliberate differences from the reel:**

- The reel's paintings are richer, hand-made art. These are procedural SVG approximations of them.
- The reel's EN/DE language switch is left out.
- The reel is a phone held in someone's hand. Here the card sits on a warm, sunlit backdrop on desktop, and fills
  the screen on phones.

## Playback

- **Replay** (bottom-right): resets every layer, closes the envelope, and plays the whole sequence again. Pressing
  it repeatedly never stacks timelines, because each run carries a token and timers left over from an earlier run
  do nothing.
- **Scrolling:** any wheel, touch or key input stops the auto tour and leaves the guest in control.
- **Reduced motion:** with `prefers-reduced-motion`, the envelope opens almost instantly, reveals are plain fades,
  the decorative loops (gulls, petals, butterflies, sway) stop, and the auto tour is off.

## Recording a reel

There is no in-page video export. The page is built from DOM elements, and browsers cannot record DOM directly.
To make a 1080×1920 clip, record the page with Playwright:

```js
const ctx = await browser.newContext({
  viewport: { width: 540, height: 960 },
  deviceScaleFactor: 2,
  recordVideo: { dir: 'out', size: { width: 1080, height: 1920 } },
})
```

Then open `/invitation/`, click `#open-btn`, wait about 50 s, and close the context. The result is a `.webm`;
convert it with `ffmpeg -i in.webm -r 30 -pix_fmt yuv420p out.mp4`. A phone's screen recorder also works.
